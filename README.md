# 精密制造车间智能质量管控与预测性维护决策支持平台

> 《制造智能技术》课程设计 · B/S 架构智能应用 Demo

## 项目简介

面向精密机加工车间，整合 **工业大数据、机器学习质量预测、深度学习预测性维护、智能排产** 四个课程章节的技术手段，构建一个 B/S 架构的智能决策支持平台。核心功能：

- **质量缺陷预测**：根据工艺参数预测产品缺陷概率并给出关键影响因子（机器学习）；
- **设备预测性维护**：基于传感器时序评估设备健康分、预警故障、估计剩余寿命（深度学习/LSTM）；
- **智能排产**：综合交期与设备健康状态生成工单排产建议（生产调度优化）；
- **车间数据看板**：产量、合格率、设备状态、预警 KPI 一屏总览。

## 数据来源

详见 [data/DATASETS.md](data/DATASETS.md)。

- **自建模拟数据**（小数据，已入库 `data/raw/`）：依据精密切削加工常识生成工艺质检数据与设备传感器时序，非真实企业数据。
- **公开数据集**（提供来源链接，未克隆大文件）：NASA C-MAPSS 涡扇发动机退化数据集，作为预测性维护 LSTM/RUL 建模范式参考。
  - 官方来源：<https://ti.arc.nasa.gov/tech/dash/groups/pcoe/prognostic-data-repository/>

## 数据预处理

预处理程序为 `scripts/preprocess.py`，处理流程：

1. **缺失值处理**：数值列中位数填充；
2. **异常值处理**：尺寸误差 > 0.20mm 截断后按中位数补全；
3. **派生特征**：材料去除率 = 切深 × 进给；
4. **类别编码**：材料 one-hot；
5. **标准化**：工艺特征 z-score（均值/标准差存于 `preprocessing_summary.json`，供后端推理复用）；
6. **时序特征工程**：传感器数据按 10 步滑动窗口提取均值/标准差/最大值；
7. **健康评分**：基于振动、温度、电流阈值计算 0–100 健康分与四级预警（正常/关注/预警/危险）。

**运行方式**：

```bash
# 1. 生成原始模拟数据
python scripts/generate_raw_data.py
# 2. 预处理 -> data/processed/
python scripts/preprocess.py
```

## 应用 Demo（B/S 全栈）

按方案已开发完成完整可运行 demo，包含：

- **前端**：数据看板、质量预测、设备运维、智能排产、基础数据 5 个页面
- **后端 API**：承载业务逻辑与三个算法模块的真实计算
- **数据库**：持久化存储设备、工单、质检记录、传感器时序
- **算法模块**：
  - 质量缺陷预测：后端根据工艺参数实时计算缺陷概率与影响因子
  - 设备健康评估：基于传感器退化数据计算健康分与预警等级
  - 智能排产：CR 规则 + 设备健康约束生成排产序列

应用预览由平台自动提供，发布需在开发页面点击"发布"按钮。
