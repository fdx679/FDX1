# 3 分钟演示视频脚本

> 课程设计：《基于深度学习与知识图谱的智能招聘简历筛选系统设计与实现》
> 用途：成果提交物之一（演示视频，3 分钟）
> 录制方式：电脑录屏（OBS / 系统自带录屏）+ 画外音，剪辑后压缩至 3 分钟内
> 录制前准备：
> 1. 在项目目录执行 `pip install -r requirements.txt`
> 2. 执行 `python run.py` 启动服务，浏览器打开 http://127.0.0.1:5000
> 3. 准备好 1~2 份真实简历文本（建议一份技术岗、一份软技能岗做对比）

---

## 分镜总览

| 段落 | 时间 | 画面 | 口播要点 |
|---|---|---|---|
| 开场 | 0:00–0:15 | 浏览器打开系统首页，展示标题栏 | 项目名称 + 解决的问题 |
| 一、系统概览 | 0:15–0:40 | 页面布局展示：岗位分类、匹配排序、知识图谱、历史记录 | 四层架构一句话带过 |
| 二、简历解析与分类 | 0:40–1:20 | 输入真实简历 → 展示解析结果（姓名/学历/经验/技能）→ 展示岗位分类 | 简历解析 + 深度学习分类 |
| 三、岗位匹配与图谱 | 1:20–2:05 | 展示匹配排序结果 → 切换到知识图谱可视化 → 展示技能缺口 | 匹配评分 + 知识图谱推理 |
| 四、收尾 | 2:05–3:00 | 回到历史记录 / 总结 | 测试通过 + 项目意义 |

## 逐镜脚本

### 镜头 1：开场（0:00–0:15）

**画面**：启动 `python run.py`，浏览器打开 http://127.0.0.1:5000，首页完整显示。

**口播**：
> 各位老师好，下面演示基于深度学习与知识图谱的智能招聘简历筛选系统。传统招聘中，简历量大、人工初筛耗时，人岗匹配精准度低。本系统用深度学习做简历分类，用知识图谱做岗位技能建模，形成从简历解析到岗位匹配的完整闭环。

### 镜头 2：系统概览（0:15–0:40）

**画面**：鼠标在页面上缓慢移动，依次指向：岗位分类区、匹配排序区、知识图谱区、历史记录区。

**口播**：
> 系统前端提供四个功能区：岗位分类、匹配排序、知识图谱可视化和历史记录。后端由 Flask 提供四组 REST 接口，数据存储在 SQLite 数据库。整体采用展示层、服务层、算法层、数据层四层架构。

### 镜头 3：简历解析与分类（0:40–1:20）

**画面**：在输入框粘贴一份真实的 Python Developer 简历 → 点击"解析简历"→ 展示解析结果卡片（姓名、学历、经验年数、技能列表）→ 展示岗位分类结果（预测岗位 + 置信度）。

**口播**：
> 下面用一份真实简历演示。提交后，系统先做简历解析，抽取姓名、学历、经验年数和技能清单，中英文技能都能识别。随后进入岗位分类模块，系统基于 TF-IDF 特征和逻辑回归模型，把这份简历分类到技术类岗位，并给出置信度。模型在 25 类岗位上的测试集准确率达到 51.6%。

### 镜头 4：岗位匹配与图谱（1:20–2:05）

**画面**：点击"岗位匹配"→ 展示岗位匹配排序表（Java 开发、Python 开发、前端开发等排名靠前，HR、Sales 排名靠后）→ 切换到"知识图谱"Tab → 展示岗位—技能图谱可视化（节点连线）→ 点选一个岗位展示技能缺口。

**口播**：
> 接下来是岗位匹配。系统综合硬技能覆盖率、分类置信度、经验年数和预测命中四个维度计算匹配分。可以看到，技术类岗位排名靠前，而 HR、Sales 这类软技能岗位不再虚高，说明区分度有效。再来看知识图谱模块，这是岗位与技能的关联网络，由 25 个岗位和 84 个技能构成。选中岗位可以查看缺失技能，为求职者补全技能提供参考。

### 镜头 5：收尾（2:05–3:00）

**画面**：切回历史记录，显示刚才的分析已被保存 → 页面切到命令行窗口，执行 `python -m pytest tests/ -q`，显示 23 passed。

**口播**：
> 每次分析都会写入历史记录，便于回看。最后，系统通过 23 项自动化测试，覆盖简历解析、岗位分类、知识图谱、匹配和 API 接口，全部通过，达到了可现场演示的状态。我的演示到此结束，谢谢各位老师。

## 制作与剪辑要点

1. **语速**：按上述口播约每分钟 220 字左右，总口播约 620 字，配画面操作自然落在 3 分钟内；若超时，优先精简镜头 4 的技能缺口部分。
2. **录屏**：分辨率建议 1920×1080，浏览器窗口最大化，鼠标移动节奏放慢，便于观看。
3. **暂停与剪辑**：粘贴简历、点击按钮等操作可分段录制，剪辑时去掉等待片段。
4. **字幕**：如条件允许，可加简体中文字幕，方便评审观看。
5. **口播与画面同步**：先念操作目的，再执行操作，避免"边做边想"。
6. **结尾黑场**：最后 1 秒留黑场，避免视频被平台截断。
