## 逐镜脚本

### 镜头 1：开场（0:00–0:20）

**画面**：桌面双击「启动智能招聘系统」快捷方式 → 黑色命令行窗口短暂出现后自动关闭、浏览器自动打开 http://127.0.0.1:5000 → 首页完整显示（标题栏 + 四大功能区）。

**口播**：
> 各位老师好，下面演示基于深度学习与知识图谱的智能招聘简历筛选系统。系统支持一键启动：双击桌面快捷方式，服务自动运行，浏览器直接打开系统页面，无需手动输入命令。传统招聘简历量大、人工初筛耗时，本系统用机器学习做简历分类、用知识图谱做岗位技能建模，形成从简历解析到岗位匹配的完整闭环。

### 镜头 2：系统概览（0:20–0:40）

**画面**：鼠标在页面上缓慢移动，依次指向：简历输入区、岗位过滤下拉框、解析与匹配结果区、知识图谱区、历史记录区。

**口播**：
> 前端提供简历输入、岗位过滤、解析匹配结果、知识图谱可视化和历史记录五个功能区。后端由 Flask 提供四组 REST 接口，数据存储在 SQLite。整体采用展示层、服务层、算法层、数据层四层架构。

### 镜头 3：简历解析与分类（0:40–1:25）

**画面**：在输入框粘贴 `docs/示例简历_PythonDeveloper.txt` 中 ALEX CHEN 的简历全文 → 点击"解析简历"→ 展示解析结果卡片（邮箱显示为 [EMAIL]、电话显示为 [PHONE]、经验 5 年、技能列表约 18 项）→ 展示岗位分类 TopK。

**口播**：
> 下面用一份真实的 Python 开发简历演示。提交后，系统先解析，抽取邮箱、电话、经验年数和技能清单，并对邮箱电话做隐私掩码保护。随后进入岗位分类模块，基于 TF-IDF 特征和逻辑回归模型给出 25 类岗位的候选排序。受训练样本规模限制，这份简历在相近技术岗位间置信度接近，这也正是系统 51.6% 准确率的真实体现——本设计已说明生产环境可替换 BERT 提升。

### 镜头 4：岗位匹配与图谱（1:25–2:20）

**画面**：在岗位过滤框中选择 Python Developer → 点击"匹配排序"→ 展示匹配结果（匹配分 55.84、技能覆盖率 87.5%、命中技能 14 项：python/flask/django/rest api/mysql/redis/docker/kubernetes/linux/git/pytest/sql/pandas/numpy；缺失技能 4 项：airflow、spark、communication、problem solving）→ 切换到知识图谱 Tab，岗位选择 Python Developer，展示岗位-技能关系图与缺失技能高亮。

**口播**：
> 接下来是岗位匹配。系统综合硬技能覆盖率、分类置信度、经验年数和预测命中四个维度加权评分。这份简历与 Python Developer 岗位匹配分 55.8，技能覆盖率达到 87.5%，命中 14 项硬技能。知识图谱模块由 25 个岗位和 84 个技能构成，选中岗位即可推理出缺失技能，例如 airflow、spark，为求职者补全技能提供明确方向。

### 镜头 5：收尾（2:20–3:00）

**画面**：切到历史记录，显示刚才的分析已入库 → 切到命令行窗口，执行 `python -m pytest tests/ -q`，显示 23 passed → 回到桌面展示「启动智能招聘系统」快捷方式。

**口播**：
> 每次分析都会写入历史记录，便于追溯。最后，系统通过 23 项自动化测试，覆盖解析、分类、图谱、匹配和 API 接口，全部通过。整个项目由 git 全程管理，并支持一键启动，达到了可现场演示的状态。我的演示到此结束，谢谢各位老师。

## 制作与剪辑要点

1. **语速**：按上述口播约 650 字、每分钟约 220 字，配画面操作自然落在 3 分钟内；若超时，优先精简镜头 4 的缺失技能列举。
2. **一键启动录制**：镜头 1 若服务已在运行，桌面快捷方式会直接开网页（黑窗一闪即关），如实录制即可；若想录"启动过程"，先关闭服务再双击。
3. **录屏**：分辨率建议 1920×1080，浏览器窗口最大化，鼠标移动节奏放慢。
4. **暂停与剪辑**：粘贴简历、点击按钮等操作可分段录制，剪辑时去掉等待片段。
5. **字幕**：如条件允许，加简体中文字幕。
6. **口播与画面同步**：先念操作目的，再执行操作，避免"边做边想"。
7. **结尾黑场**：最后 1 秒留黑场，避免视频被平台截断。
