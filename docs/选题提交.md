## 二、技术方向映射表

说明每个技术方向在本系统中的**实际作用**（非装饰性引入，答辩时须能讲清）。

| 序号 | 技术方向 | 所属课程专题 | 在本系统中的实际作用 | 落地模块 |
|------|----------|--------------|----------------------|----------|
| 1 | 深度学习 | 人工智能基础 | 简历文本语义理解与岗位分类（生产方案为 BERT 预训练模型；本演示系统为可本地运行的 TF-IDF+逻辑回归实现，接口可无缝替换为 BERT） | `app/models/classifier.py` |
| 2 | 知识图谱 | 人工智能基础 | 构建「岗位→技能」知识图谱，支撑岗位技能查询、技能反查、缺失技能推理、图谱可视化 | `app/models/skill_graph.py`（networkx；生产可换 Neo4j） |
| 3 | 机器学习 | 人工智能基础 | 逻辑回归多分类模型进行候选人岗位分类与匹配度排序权重优化 | `app/models/classifier.py`、`matcher.py` |
| 4 | Web 开发 | 补充技术 | Flask 后端 REST API + 前端演示页面（HTML/CSS/JS + ECharts） | `app/`、`app/static/` |
| 5 | 数据库 | 补充技术 | SQLite 存储简历、候选人分析与历史记录（生产可换 MySQL） | `app/database.py` |
| 6 | 自然语言处理 | 补充技术 | jieba 中文分词 + 技能词表，实现中英文简历技能抽取 | `app/models/skill_extractor.py` |

## 三、系统架构草图

```
┌─────────────────────────────────────────────────────────────┐
│                      前端演示界面（HTML/CSS/JS+ECharts）         │
│        简历输入 → 解析结果展示 → 匹配排名 → 图谱可视化 → 历史记录     │
└──────────────────────────┬──────────────────────────────────┘
                           │ REST API (JSON)
┌──────────────────────────▼──────────────────────────────────┐
│                    后端服务（Flask）                           │
│   /api/resume/parse  /api/match/rank  /api/graph/*  /api/system │
└───────┬──────────────┬──────────────┬──────────────┬─────────┘
        │              │              │              │
┌───────▼───────┐ ┌────▼─────────┐ ┌──▼──────────┐ ┌▼───────────┐
│ 简历解析模块   │ │ 分类器       │ │ 知识图谱    │ │ 匹配器     │
│ resume_parser │ │ TF-IDF+逻辑回归│ │ networkx   │ │ matcher    │
│ 技能抽取      │ │ 25 类岗位     │ │ 岗位→技能   │ │ 多维融合   │
└───────┬───────┘ └────┬─────────┘ └──┬──────────┘ └┬───────────┘
        │              │              │              │
        └──────────────┴──────┬───────┴──────────────┘
                              │
                    ┌─────────▼─────────┐
                    │  数据层             │
                    │ data/raw（原始）     │
                    │ data/preprocessed  │
                    │ SQLite（app/data.db）│
                    └───────────────────┘
```

**业务闭环**：简历上传 → 文本解析 → 岗位分类 → 技能抽取 → 知识图谱推理（缺失技能） → 多维匹配排序 → 前端可视化展示 → 历史记录入库。

## 四、数据来源

| 数据集 | 来源 | 规模 | 用途 |
|--------|------|------|------|
| 简历数据集（主） | Kaggle Resume Dataset：https://www.kaggle.com/datasets/snehaanbhawal/resume-dataset | 仓库内置 169 条（25 类），完整版约 2400 条 | 简历分类训练、解析演示 |
| 岗位描述数据集（辅） | Indeed 公开样本：https://github.com/luminati-io/Indeed-dataset-samples | 筛选 55 条 | 岗位技能知识图谱 |
| 自建岗位补充（辅） | 人工整理 | 16 条 | 补齐技术类岗位，覆盖 25 类 |

> 数据合规：全部来自公开数据集或自建演示数据，无私有敏感信息；简历预处理已做隐私掩码。详见 `data/README.md`。
