# 需求规格说明书

## 基于深度学习与知识图谱的智能招聘简历筛选系统

- 文档编号：FDX1-SRS-001
- 版本：V1.0
- 日期：2026-09-02

---

## 1. 引言

### 1.1 编写目的
本说明书定义智能招聘简历筛选系统的功能需求、数据需求、非功能需求与验收标准，作为系统设计与开发（规格驱动开发）的依据。

### 1.2 项目背景
传统简历筛选依赖人工阅读与关键词匹配，效率低、主观性强、缺乏可解释性。本课程设计融合深度学习（文本语义）、知识图谱（结构化推理）与机器学习（匹配排序），实现简历自动解析、候选人技能匹配打分、岗位推荐排序，输出可解释的筛选结果。

### 1.3 术语
| 术语 | 说明 |
|------|------|
| 简历解析 | 从简历文本抽取姓名、学历、技能、经验等结构化信息 |
| 岗位分类 | 将简历映射到 25 个岗位类别之一 |
| 知识图谱 | 岗位与技能之间的有向关系图 |
| 匹配度 | 候选人技能与岗位要求的综合匹配分数（0-100） |

| FR-3.3 | 缺失技能推理（简历技能 vs 岗位要求） | 高 |

### 2.4 匹配排序（FR-4）

## 3. 数据需求

| 数据集 | 来源 | 规模 | 用途 |
|--------|------|------|------|
| 简历数据 | Kaggle Resume Dataset（公开） | 169 条 / 25 类 | 训练/测试分类模型 |
| 岗位数据 | Indeed 公开样本 + 自建补充 | 71 条 / 25 类 | 构建知识图谱 |
| 岗位-技能关系 | 预处理生成 | 291 条 / 85 技能 | 图谱节点与边 |

数据说明详见 `data/README.md`。

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|------|------|------|
| NFR-1 | 可现场演示 | 本地一键启动，无外网依赖（ECharts 本地化、模型本地训练） |
| NFR-2 | 隐私合规 | 简历中邮箱/电话/身份证一律掩码，不入库真实个人信息 |
| NFR-3 | 可测试性 | pytest 自动化测试覆盖全部模块与 API |
| NFR-4 | 可解释性 | 匹配结果含命中/缺失技能提示 |
| NFR-5 | 可追溯 | git 全程版本管理，prompt 交流记录留存 |
| NFR-6 | 响应性能 | 单次匹配分析响应 < 3 秒（本地环境） |

## 6. 验收标准

| 编号 | 验收项 | 标准 |
|------|--------|------|
| AC-1 | 自动化测试 | `pytest tests/` 全部通过（23 项） |

## 7. 假设与限制

1. 简历分类采用 TF-IDF+逻辑回归（可本地训练）；生产环境可替换 BERT 预训练模型提升准确率（数据规模限制下当前准确率约 52%）。
2. 知识图谱采用 networkx 实现；生产环境可替换 Neo4j 图数据库。
3. 数据库采用 SQLite；生产环境可替换 MySQL。
4. 前端为静态页面（HTML/CSS/JS+ECharts），零构建、离线可运行；生产可升级为 Vue3 工程。
