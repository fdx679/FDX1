# Prompt 目录说明（/prompt）

本目录用于**AI工具提示词追溯**，记录课程设计开发全流程中与 AI 助手的交流记录，保证开发过程可追溯、可复现。

## 目录约定

- `conversation_log.json`：AI 交流记录主文件（JSON 格式），按时间顺序记录每个阶段的用户需求与 AI 执行摘要。
- 每个开发阶段结束、**上下文压缩前**，都会及时将最新交流记录备份并追加到此文件，避免丢失。

## 记录字段说明

| 字段 | 说明 |
|------|------|
| `turn_id` | 交流轮次编号 |
| `timestamp` | 记录时间 |
| `stage` | 所属开发阶段（数据准备 / 数据预处理 / prompt追溯 / ...） |
| `user_message` | 用户输入（提示词） |
| `ai_summary` | AI 执行摘要（做了什么、关键决策） |
| `artifacts` | 本阶段产出的文件/链接 |

## 更新机制

后续每个开发阶段（模型训练、知识图谱构建、Web系统开发、测试部署等）完成后，将追加新的交流记录到 `conversation_log.json`，并在 README.md 中同步说明。
